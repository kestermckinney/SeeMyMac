# SeeMyMac 0.3.1

- SeeMyMac stays disconnected when the Remote Desktop server ends your session, such as when you sign out or another client takes over.
- Remote sessions receive horizontal scroll and keyboard modifiers you were already holding.
- The update dialog shows the full release notes.

## Installing on macOS

1. Download `SeeMyMac-0.3.1-macOS.pkg` and open it. It is signed with a Developer ID and notarized by Apple, so it opens without a Gatekeeper warning.
2. Follow the installer. It puts **SeeMyMac** in the `Applications` folder inside your home folder (`~/Applications`) without asking for a password, which also lets SeeMyMac update itself.
3. Open **SeeMyMac** from `~/Applications` (or Spotlight).

## Installing on Windows

Download and run `SeeMyMac-0.3.1-setup.exe`. One installer covers both ARM64 and Intel/AMD PCs and installs for your account only, without administrator rights.
